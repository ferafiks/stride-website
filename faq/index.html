Platforms

Stride currently supports Windows, Linux, macOS, Android and iOS. For more information, check out Platforms in our documentation.

Currently Stride's editor is only available on Windows. However, you are able to write code and build games on Linux and macOS without it, which makes it possible to create code-only projects using the community toolkit.

Linux users can also use Game Studio via Proton. For more information, visit our official Proton setup guide in the documentation.

Currently, there is no official support for consoles, but due to being open-source, it's possible to fork the engine and add the support yourself.

Currently, Stride does not support deploying games to web, as our focus remains on desktop and mobile.
